# TracePilot 使用说明（页面切换与视频浏览增强版）

## 概述

基于 eBPF + Perfetto 的交互关键路径图卡顿分析系统。构建 17 种节点 × 12 种边的异构有向图，用图算法计算 CriticalScore，定位卡顿根因。

支持 `--scenario page_switch`（默认）和 `--scenario video` 双场景。

## 环境要求

**设备端**: Pixel 6a, Android 15 (kernel 6.1), root, BTF 可用
**编译环境**: WSL Ubuntu, clang/gcc/ndk r26b, libbpf

```bash
sudo apt install clang gcc libbpf-dev libelf-dev zlib1g-dev
```

## 编译

```bash
cd ~/pixel6a-bpf/页面切换-增强版
make bpf      # 13 hooks, 9 maps
make loader   # 宿主机 loader
make android  # 设备端 aarch64 loader
```

## 采集

```powershell
cd "D:\osh大作业\页面切换-增强版"

adb push output\tracepilot-aarch64 /data/local/tmp/tracepilot
adb push output\tracepilot.bpf.o /data/local/tmp/
adb push scripts\perfetto_config.pbtx /data/local/tmp/
adb shell "su -c 'chmod +x /data/local/tmp/tracepilot'"

adb shell "perfetto --txt -c /data/local/tmp/perfetto_config.pbtx -o /sdcard/perfetto_trace.perfetto-trace --background"
adb shell "su -c '/data/local/tmp/tracepilot -d 60 -e /data/local/tmp/events.bin -D'"

adb pull /sdcard/perfetto_trace.perfetto-trace output\
adb pull /data/local/tmp/events.bin output\tracepilot_events.bin
```

## 提取帧数据

```bash
trace_processor_shell -q scripts/frame_query.sql output/perfetto_trace.perfetto-trace > output/frames.txt
```

## 分析

```powershell
# 页面切换
.\output\tracepilot.exe -i output\tracepilot_events.bin `
  -f output\frames.txt -o output\result.json -G -k 10 -D

# 视频场景
.\output\tracepilot.exe -i output\tracepilot_events.bin `
  -f output\frames.txt -o output\result.json -G -s video -k 10 -D
```

## 评分公式

### 页面切换（默认权重）

```
CriticalScore =
    0.30 × frame_window_overlap
  + 0.10 × log1p(runnable_delay_p95_ms)
  + 0.25 × binder_dependency_centrality
  + 0.10 × futex_wait_contribution
  + 0.20 × render_path_proximity
  + 0.05 × repeated_jank_cooccurrence
  - 0.05 × background_penalty
```

### 视频场景（`--scenario video` 权重）

```
CriticalScore_video =
    0.15 × frame_window_overlap
  + 0.10 × log1p(runnable_delay_p95_ms)
  + 0.15 × binder_dependency_centrality
  + 0.05 × futex_wait_contribution
  + 0.10 × render_path_proximity
  + 0.05 × repeated_jank_cooccurrence
  - 0.05 × background_penalty
  + 0.20 × decode_path_proximity          ← BFS to VideoDecode
  + 0.10 × thermal_proximity              ← 温控降频
  + 0.15 × buffer_underrun_contribution   ← 缓冲区饥饿
  - 0.05 × network_penalty
```

## 关键指标计算

| 指标 | 算法 |
|------|------|
| `binder_dependency_centrality` | Brandes betweenness centrality on binder subgraph |
| `render_path_proximity` | BFS from RenderThread/SurfaceFlinger, proximity = 1/(1+d) |
| `decode_path_proximity` | BFS from VideoDecode nodes, proximity = 1/(1+d) |
| `thermal_proximity` | thermal_proximity × decode_path_proximity |
| `frame_window_overlap` | jank frames where thread active / total jank frames |

## 卡顿原因分类

| 类别 | 判定 | 场景 |
|------|------|------|
| CPU_CONTENTION | PREEMPTED_BY 边密集 | 通用 |
| BINDER_BLOCKING | BINDER_CALL 边密集 | 通用 |
| FUTEX_BLOCKING | FUTEX_WAIT 边密集 | 通用 |
| IO_WAIT | 系统 IRQ/SoftIRQ 占比高 | 通用 |
| MEMORY_RECLAIM | RESOURCE_STALL 出现 | 通用 |
| RUNNABLE_DELAY | runnable_delay_p95 高 | 通用 |
| VIDEO_LATE_RENDER | DECODE_DEPENDENCY 边密集 | 视频 |
| AUDIO_SYNC_DRIFT | 预留 | 视频 |
| THERMAL_THROTTLE | THERMAL_STALL 边出现 | 视频 |

## 故障排查

| 问题 | 排查方法 |
|------|----------|
| BPF 加载失败 | `adb shell "su -c 'dmesg \| grep -i bpf'"` |
| enhanced_events 为空 | `adb shell "su -c 'ls /sys/kernel/debug/tracing/events/binder/'"` |
| binder centrality 全 0 | 确认采集期间有跨进程 binder 调用 |
| 视频场景未检测到 | 确认线程名含 VideoDecode/CCodec/ACodec |
| 乱码文件 | 用 `cat` 而非 Windows 记事本打开，确保 UTF-8 编码 |
