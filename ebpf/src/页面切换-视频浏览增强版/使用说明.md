# TracePilot 使用指南（页面切换与视频浏览增强版）

## 概述

TracePilot 通过 **Perfetto 定 jank 帧** + **eBPF 建关键路径图** + **Inference 推断根因** + **Hint Engine 输出调控建议**，支持页面切换与视频浏览两个独立场景。

## 环境要求

| 端 | 要求 |
|----|------|
| 设备 | Pixel 6a, Android 15, root, BTF |
| 编译 | WSL Ubuntu, clang, libbpf-dev |
| 分析 | trace_processor_shell（Perfetto） |

```bash
sudo apt install clang gcc libbpf-dev libelf-dev zlib1g-dev
```

## 编译

```bash
cd "页面切换-增强版"
make bpf && make loader && make android
```

## 分场景采集（重要：不要混采）

### WSL / Bash

```bash
# 1. 页面切换 — 只切 Tab/页面，不要播视频
./scripts/deploy.sh --scenario page_switch --package com.your.app --duration 30

# 2. 视频浏览 — 连续播放，少切页面
./scripts/deploy.sh --scenario video --package com.your.app --duration 30
```

### PowerShell

```powershell
.\scripts\deploy.ps1 -Scenario page_switch -Package com.your.app -Duration 30
.\scripts\deploy.ps1 -Scenario video       -Package com.your.app -Duration 30

# 两场景采完后对比（WSL 中执行，与 Bash 相同）
./output/tracepilot --compare-dir output --compare-out output/compare_report.json
```

### 每场景输出目录

```
output/page_switch/   或   output/video/
├── events.bin
├── frames.txt
├── thermal_profile.txt      ← thermal_query.sql 提取
├── perfetto_trace.perfetto-trace
├── identity_map.json
├── result.json              ← 含 inference + hints
├── hints.json
└── graph_*.json / .dot
```

## 离线分析

```bash
./output/tracepilot \
  -i output/page_switch/events.bin \
  -f output/page_switch/frames.txt \
  --thermal-data output/page_switch/thermal_profile.txt \
  -o output/page_switch/result.json \
  -G -k 10 -s page_switch -p com.your.app -D
```

| 参数 | 说明 |
|------|------|
| `-G` | 图模式 CriticalScore |
| `-s page_switch\|video` | 场景权重模板 |
| `-p PKG` | 目标包名（离线补 package） |
| `--thermal-data` | 温控曲线（可选，自动从 frames 同目录找） |
| `--hint-apply` | 设备上真下发 Hint（默认 dry-run） |

## Step 3：多会话 / 多场景对比

两个场景各采完后：

```bash
./output/tracepilot --compare-dir output \
  --compare-out output/compare_report.json
```

自动扫描 `output/page_switch/result.json`、`output/video/result.json` 等，输出：

- 各会话 jank 率、主因、Top-1 线程
- Top-1 重叠矩阵（跨场景 culprit 是否一致）

## 手动提取帧 / 温控

```bash
trace_processor_shell -q scripts/frame_query.sql \
  output/page_switch/perfetto_trace.perfetto-trace > output/page_switch/frames.txt

trace_processor_shell -q scripts/thermal_query.sql \
  output/page_switch/perfetto_trace.perfetto-trace > output/page_switch/thermal_profile.txt
```

## Inference 规则（Step 3）

多信号融合，非单一指标：

| 证据 signal | 含义 |
|-------------|------|
| `binder_centrality` | Binder 子图在 jank 窗口活跃 |
| `runnable_delay` | 关键线程 wakeup-to-run 延迟高 |
| `thermal_throttle` | 温控温升 + 大核降频 |
| `futex_wait` | Render/UI 线程 futex 阻塞 |
| `decode_late` | 视频解码路径滞后 |

`recommended_hint` 由主导因自动映射到 Hint 类型。

## 故障排查

| 问题 | 处理 |
|------|------|
| 两场景数据混在一起 | 分开采集，使用 `--scenario` |
| `thermal_profile.txt` 为空 | 正常时可依赖 CPU 降频比；确认 trace 含 `power/thermal_temperature` |
| compare 找不到 result | 确认 `output/<场景>/result.json` 存在 |
| VD 帧为 0（video） | 采集时持续播放视频，检查 `frame_query.sql` |
| package 为空 | 加 `-p` 或提供 `identity_map.json` |
