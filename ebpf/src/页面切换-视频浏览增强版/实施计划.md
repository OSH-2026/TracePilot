## Step 3（研究扩展）— 本次完成

### Task 14: Thermal 深化 ✅

| 模块 | 文件 | 说明 |
|------|------|------|
| SQL 提取 | `scripts/thermal_query.sql` | 从 Perfetto 提取 `timestamp_ns temp_mc` |
| 加载/聚合 | `loader/thermal_profile.c` | jank 窗口温升、peak、throttle_score |
| 图集成 | `thermal_profile_apply_to_graph()` | 更新 `freq_throttle_ratio`、`thermal_proximity` |
| 分类增强 | `classify_jank_causes()` | 融合降频 + 温升 → `THERMAL_THROTTLE` |
| 输出 | `resource_stats.thermal_*` | baseline/peak/jank_delta/throttle_score |
| 采集 | `deploy.sh` | 自动提取 `thermal_profile.txt` 并传入分析 |

### Task 15: Inference-aware 证据链 ✅

| 模块 | 文件 | 说明 |
|------|------|------|
| 融合引擎 | `loader/inference_engine.c` | 多信号加权 → hypothesis + confidence |
| 证据 | `inference.frame_inferences[].evidence[]` | binder / rd / thermal / futex / decode |
| Hint 映射 | `recommended_hint` | 主导因 → Hint 类型建议 |
| 输出 | `result.json` → `"inference"` 段 | 最多 32 条 jank 帧推断 |

### Task 16: Multi-session 对比 ✅

| 模块 | 文件 | 说明 |
|------|------|------|
| 快照解析 | `loader/session_compare.c` | 读 result.json 摘要 |
| 目录扫描 | `--compare-dir output` | 自动找 page_switch/video 等 |
| 报告 | `compare_report.json` | jank 率、主因、Top-1、overlap 矩阵 |
| CLI | `tracepilot --compare-dir --compare-out` | 独立模式，无需 events.bin |

### Task 17–19: 未实施（建议写进「未来工作」）

| 项 | 原因 |
|----|------|
| **Learned policy** | 需多 trace 标注 + ML 管线，样本不足易过拟合 |
| **Cuttlefish** | 换仿真环境，部署链完全重做 |
| **sched_ext** | Pixel 6a kernel 6.1 通常无 sched_ext，需换内核 |

## 评分模型

### 页面切换

```
CriticalScore = 0.30×overlap + 0.10×log1p(rd) + 0.25×binder
              + 0.10×futex + 0.20×render - 0.05×bg
```

### 视频

```
CriticalScore = 0.15×overlap + 0.10×log1p(rd) + 0.15×binder
              + 0.05×futex + 0.10×render - 0.05×bg
              + 0.20×decode + 0.10×thermal + 0.15×buffer - 0.05×net
```

`thermal` 项在 Step 3 中由 `thermal_profile` + `freq_throttle_ratio` 联合驱动。

## 已知局限

- `thermal_query.sql` 依赖 trace 内是否有 thermal 事件；无则回退 CPU 降频推断
- Inference 为规则融合，非 ML 模型
- Multi-session 对比目前以 Top-1 tid 重叠为主，未做 full top-k set overlap
- Learned policy / sched_ext 留作 future work
