# TracePilot 实施计划（页面切换与视频浏览增强版）

## 上下文

- **设备**: 已 root 的 Pixel 6a, Android 15 (kernel 6.1), 支持 BTF/CO-RE
- **框架**: libbpf 原生 API（`bpf_object__open_file()` 等），不依赖 bpftool skeleton
- **BPF**: 13 个 raw_tp/tp hook（7 原有 + 6 新增），9 个 maps（3 RINGBUF + 6 HASH）
- **编译**: WSL Ubuntu, NDK r26b android34-clang
- **场景**: 页面切换（默认）+ 视频播放（`--scenario video`）

## BPF Maps

| Map | 类型 | 大小 | 用途 |
|-----|------|------|------|
| `events` | RINGBUF | 16MB | sched_switch/wakeup |
| `sys_events` | RINGBUF | 4MB | IRQ/SoftIRQ |
| `enhanced_events` | RINGBUF | 4MB | binder/futex/cpufreq/mem |
| `wakeup_times` | HASH | 10240 | tid -> wakeup timestamp |
| `preempt_times` | HASH | 10240 | tid -> preempt timestamp |
| `irq_start_times` | HASH | 256 | (cpu<<32\|irq) -> entry |
| `softirq_start_times` | HASH | 64 | (cpu<<32\|vec) -> entry |
| `futex_wait_times` | HASH | 2048 | tid -> futex wait start |

## 架构

```
设备端                                      宿主机
Perfetto + eBPF 并行采集              trace_processor_shell 提取帧
  13 hooks -> events.bin (v3)   --->   tracepilot -G [-s video] -> result.json
```

- 时钟对齐: eBPF (CLOCK_MONOTONIC) -> Perfetto (CLOCK_BOOTTIME)，自动检测偏移
- v3 格式向后兼容 v1/v2

## 图模型

**17 种节点**: FRAME, UI_THREAD, RENDER_THREAD, BINDER_CLIENT, BINDER_SERVER, SYSTEM_SERVER, SURFACEFLINGER, FUTEX_WAIT, CPU_RESOURCE, MEMORY_RECLAIM, IO_WAIT, VIDEO_DECODER, AUDIO_THREAD, MEDIA_SERVER, NETWORK, THERMAL, BUFFER_QUEUE

**12 种边**: WAKEUP, RUNNABLE_WAIT, BINDER_CALL, FUTEX_WAIT, CPU_RUN, PREEMPTED_BY, FRAME_DEPENDENCY, RESOURCE_STALL, DECODE_DEPENDENCY, BUFFER_QUEUE, THERMAL_STALL, NETWORK_WAIT

**边权重**: duration_ns, p95_ns, count, critical_window_overlap_ratio, jank_overlap_score

## 评分模型

### 页面切换

```
CriticalScore = 0.30×frame_overlap + 0.10×log1p(rd) + 0.25×binder_centrality
              + 0.10×futex + 0.20×render_proximity + 0.05×jank_cooccur - 0.05×bg
```

### 视频场景

```
CriticalScore = 0.15×frame_overlap + 0.10×log1p(rd) + 0.15×binder_centrality
              + 0.05×futex + 0.10×render_proximity + 0.05×jank_cooccur
              - 0.05×bg + 0.20×decode_proximity + 0.10×thermal + 0.15×buffer - 0.05×net
```

## 实施任务

### Task 1-7: 基础版 — 已完成
7 个 tp hook（sched_switch/wakeup, irq/softirq entry/exit）、6 maps、双 ring buffer、Python 离线分析、Perfetto 配置、多 App 测试

### Task 8: Binder dependency graph — 已完成
- BPF: `raw_tp/binder_transaction` + `raw_tp/binder_transaction_received`
- 匹配: CALL/RECEIVED 按 5ms 时间窗配对
- 图算法: Brandes betweenness centrality

### Task 9: Futex wait graph — 已完成
- BPF: `raw_tp/sys_enter` + `raw_tp/sys_exit` filter __NR_futex=98
- 图边: FUTEX_WAIT 边 + 等待时长

### Task 10: CPU frequency / big-little — 已完成
- BPF: `raw_tp/cpu_frequency`
- cluster: CPU0-3=little, 4-5=big, 6-7=prime
- 降频检测: min_cpu_freq_big_khz / avg_cpu_freq_big_khz

### Task 11: Jank cause classifier — 已完成
- 逐帧扫描边权重，取最大信号为主因
- 11 分类(7 通用 + 3 视频 + 1 UNKNOWN)

### Task 12: Heuristic comparison — 已完成
- 同时计算旧加权和新图算法评分
- 对比 top-k overlap 和 SNR

### Task 13: 视频场景扩展 — 已完成
- Perfetto 配置: 新增 video/audio/media atrace
- frame_query.sql: 解码帧查询（dual track: UI + 视频）
- classify_thread: 识别 VideoDecode/CCodec/ACodec/AudioTrack
- video_extend_graph: 新增 6 节点/4 边
- compute_decode_proximity: BFS from VideoDecode
- compute_thermal_proximity: 基于 freq drop ratio
- get_scenario_weights: 页面切换 vs 视频双权重模板
- run_video_scenario: 视频完整分析流水线
- --scenario flag: main.c 新增 -s 参数
