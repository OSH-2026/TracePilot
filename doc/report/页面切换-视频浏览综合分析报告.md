## 三、跨 Session 对比分析

### 3.1 Top 线程对比

| # | Run 1 | Run 2 | Video |
|---|-------|-------|-------|
| 1 | tid 103（0.825） | tid 16945 emitExt_tracker（0.856） | tid 103（0.746） |
| 2 | tid 52 rcuop/4（0.567） | tid 16689 Thread-17（0.650） | tid 66 rcuop/6（0.582） |
| 3 | tid 66 rcuop/6（0.473） | **tid 103**（0.455） | tid 52 rcuop/4（0.579） |
| 4 | tid 48（0.459） | tid 48（0.425） | tid 51（0.482） |
| 5 | tid 51（0.306） | tid 12849 kworker（0.393） | tid 48（0.350） |

**tid 103** 在三次 session 全部进入 Top-3（Run 1 #1, Run 2 #3, Video #1），是跨场景最稳定的嫌疑线程。  
**tid 48** 三次均出现在 Top-5。  
内核 RCU 线程（rcuop/4, rcuop/6）在 Run 1 和 Video 中占据高位，Run 2 中未被突出。

### 3.2 图特征对比

| 边类型 | Run 1 | Run 2 | Video | 视频 vs 页面切换 |
|--------|:-----:|:-----:|:-----:|:---------------:|
| BINDER_CALL | 52 | 53 | 45 | - |
| FUTEX_WAIT | 2371 | 1770 | 1977 | - |
| **RESOURCE_STALL** | 51 | 13 | **247** | **5–19x** |
| **DECODE_DEPENDENCY** | 567 | 0 | **560** | 视频独有 |
| **BUFFER_QUEUE** | 4 | 0 | **12** | 视频独有 |
| **NETWORK_WAIT** | 19 | 0 | **25** | 视频独有 |

**关键发现：** 视频场景的 RESOURCE_STALL（247）是页面切换场景（13–51）的 5 到 19 倍，体现视频解码对 CPU/GPU 资源的更高争用。DECODE_DEPENDENCY 和 BUFFER_QUEUE 是视频场景独有的图结构特征。

### 3.3 CPU 频率对比

| 指标 | Run 1 | Run 2 | Video |
|------|:-----:|:-----:|:-----:|
| 小核平均频率 | 1,673 MHz | 1,640 MHz | **1,733 MHz** |
| 大核平均频率 | 2,093 MHz | 2,051 MHz | **2,209 MHz** |

视频场景 CPU 频率均最高（大核 +116–158 MHz），符合视频播放对 CPU + GPU 的复合负载需求。

### 3.4 Futex / Binder 负载对比

| 指标 | Run 1 | Run 2 | Video |
|------|:-----:|:-----:|:-----:|
| Futex wait 次数 | **202,944** | 135,108 | **244,012** |
| Binder 调用次数 | **32,711** | 27,565 | 25,417 |
| Binder 阻塞 | 7.55 ms | 4.50 ms | 3.88 ms |

视频场景 Futex wait 最高（244K），体现多线程并发同步压力；Binder 负载三组相近。

### 3.5 Thermal 对比

| 指标 | Run 1 | Run 2 | Video |
|------|:-----:|:-----:|:-----:|
| 温度传感器 | neutral_therm | VIRTUAL-SKIN + skin_therm2 | charger_skin + usb_pwr |
| 样本数 | 1 | **10** | 3 |
| 温度范围 | 31.4°C（单点） | **36.8→41.5°C** | 30.3→52.3°C |
| throttle_score | 0.00 | **0.47** | 1.00 |

Run 1 仅 1 个温度点不足以触发降频；Run 2 在 30 秒内温升 4.7°C，触发轻度降频（throttle=0.47）；Video 的 charger_skin_therm 读数偏高（52°C，可能是充电芯片温度），导致 throttle=1.00。三次 session 使用了不同的温度传感器轨道，与设备端 thermal HAL 状态有关。

### 3.6 Jank 根因一致但场景差异显著

无论页面切换还是视频浏览，所有 jank 帧的根因均被分类为 **RUNNABLE_DELAY**。但图结构展示了两种场景的本质差异：

- **页面切换**：核心特征为 FUTEX_WAIT 密集 + UI 线程阻塞，无 Decode/Buffer/Network 边
- **视频浏览**：在 RUNNABLE_DELAY 基础上叠加了 DECODE_DEPENDENCY（560） + RESOURCE_STALL（247）+ NETWORK_WAIT（25），体现视频播放的多维资源争用
